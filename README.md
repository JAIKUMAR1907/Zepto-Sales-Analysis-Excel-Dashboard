# 🛒 Zepto Sales Analysis -- Excel Dashboard

## 📌 Project Overview

This project analyzes Zepto sales data using Microsoft Excel. An
interactive dashboard was created to monitor sales performance, order
trends, product performance, customer segments, payment methods, and
delivery status.

## 🎯 Project Objectives

-   Analyze overall sales and order performance.
-   Track monthly sales trends.
-   Identify top-performing products.
-   Understand payment method preferences.
-   Compare customer types across cities.
-   Monitor daily quantity trends and delivery status.

## 🛠️ Tools & Skills

-   Microsoft Excel
-   Data Cleaning and Analysis
-   Pivot Tables and Pivot Charts
-   Slicers and Interactive Dashboard Design

## 📈 Dashboard Features

1.  **Sales Trend by Month** -- Displays monthly sales performance.
2.  **Payment Method Contribution** -- Shows the share of orders by
    payment method.
3.  **Top 10 Products** -- Highlights the top products by sales.
4.  **Sales by Customer Type Across Cities** -- Compares Bulk, New, and
    Returning customers across cities.
5.  **Quantity Volume Over Days** -- Shows daily quantity movement.

## 🎛️ Interactive Filters

The dashboard includes slicers for: - City - Month - Payment Method -
Delivery Status

Use these filters to interactively explore the dashboard.

## 💡 Key Observations

-   The dashboard reports total sales of ₹5,63,992.30 from 1,500 orders.
-   UPI has the largest contribution among the displayed payment
    methods.
-   Bulk customers contribute a significant share of sales across the
    displayed cities.
-   Product-level analysis helps identify the leading products.
-   Daily quantity analysis makes changes in order volume easier to
    track.
